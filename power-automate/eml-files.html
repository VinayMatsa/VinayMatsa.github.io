Building .eml files

VM Vinay Matsa 21 November 2026 3 min read

An .eml file is an email saved as a text file. Double-click it and Outlook opens it as a message. Flows create them to keep a copy of what was sent, to hand someone a ready-made draft, or to archive an email next to the record it belongs to.

An .eml built in a Compose

An .eml file is just headers, a blank line, then the body. The demo builds one in a Compose and saves it with SharePoint Create file:

From: Contoso Support <support@contoso.com>
To: Alex Johnson <alex@contoso.com>
Subject: Request REQ-1042 received
Date: Sun, 22 Nov 2026 10:06:04 +0000
MIME-Version: 1.0
Content-Type: text/html; charset=utf-8

<p>Hello Alex,</p><p>We received request <b>REQ-1042</b>.</p>

The line-break detail

Email headers must be separated by a carriage return and line feed. A Compose box doesn't make that obvious, so the demo inserts them with an expression:

concat('From: ...', decodeUriComponent('%0D%0A'), 'To: ...', decodeUriComponent('%0D%0A'), ...)
PieceWhat it does
decodeUriComponent('%0D%0A')Produces a real carriage return and line feed between headers.
two in a rowMake the blank line that separates the headers from the body.
Content-Type: text/htmlTells Outlook the body is HTML; use text/plain for plain text.

Drafts that open ready to send

Add the header X-Unsent: 1 and Outlook opens the file as a new draft instead of a received message, so a person can review and press Send. Leave out From in that case; Outlook uses the person's own account.

New to this? Start from the basics optional

Headers: the lines at the top of an email (From, To, Subject, Date) that describe it.

MIME: the standard format for email content, including how attachments are added.

Build it step by step optional
  1. Add a Compose that builds the headers and body with concat() and decodeUriComponent('%0D%0A') between lines.
  2. Add SharePoint Create file with a name ending in .eml and the Compose output as content.
  3. Download the file and open it in Outlook to check the layout.
  4. For a draft, add X-Unsent: 1 and remove the From line.

Common mistakes

  • Plain line breaks typed in the box. Some clients then show headers as body text.
  • No blank line between headers and body. The body disappears.
  • Putting real customer emails into archived .eml files without a retention plan.
