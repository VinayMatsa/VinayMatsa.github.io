Building .eml files

VM Vinay Matsa 21 November 2026 3 min read

An .eml file is an email saved as text. Double-click it and Outlook opens it as a message. Flows create them to keep a copy of what was sent, to hand someone a draft, or to archive an email next to its record.

An .eml built in a Compose

WhatHeaders, a blank line, then the body, saved with Create file as .eml.
WhyA complete, openable record of a message, stored where the team works.
DemoA confirmation for request REQ-1042.

Structure of an .eml

Headers: From, To, Subject, Date, MIME-Version, Content-Type
A blank line
Body (HTML)
Create file website-demo-REQ-1042.eml
From: Contoso Support <support@contoso.com>
To: Alex Johnson <alex@contoso.com>
Subject: Request REQ-1042 received
Date: Sun, 22 Nov 2026 10:06:04 +0000
MIME-Version: 1.0
Content-Type: text/html; charset=utf-8

<p>Hello Alex,</p><p>We received request <b>REQ-1042</b>.</p>

The line-break detail

Headers must be separated by a carriage return + line feed (CRLF). A Compose box doesn't make that obvious, so insert them with an expression:

concat('From: ...', decodeUriComponent('%0D%0A'), 'To: ...', decodeUriComponent('%0D%0A'), ...)
PieceWhat it does
decodeUriComponent('%0D%0A')Produces a real CRLF line break.
concat(...)Joins headers with the breaks between them.

Common mistakes

  • Plain line breaks instead of CRLF, so headers merge.
  • Missing the blank line before the body.
  • Keeping From in a draft.
