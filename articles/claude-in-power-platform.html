Four ways to put Claude to work in Microsoft Power Platform

VM Vinay Matsa 13 November 2026 2 min read

Same model, four ways in. Each one fits a different kind of Power Platform work.

Start from the root

Claude is Anthropic's family of AI models. You can reach it through different apps, and each app gives it different abilities: some can run commands on your machine, some can read your data through connectors, some can see the web page you're on. Choosing the right entry point is mostly about what you want it to touch.

The four options

OptionBest for
1. Claude Code (terminal)Building apps, flows and Power Pages with Microsoft's power-platform-skills plugins, using pac and the Azure CLI
2. Claude Code in VS CodeThe same engine, but every change shows as a diff you review before accepting
3. Claude Desktop with the Dataverse MCP serverAsking questions of your Dataverse data in plain language (also works in Claude Code)
4. Claude in Chrome (browser extension)Working inside Copilot Studio, Power Apps and Power Automate pages

Bonus: inside Copilot Studio you can choose a Claude model as an agent's primary model, if your admin allows it.

It signs in as you

Whichever option you use, Claude acts with your identity. Microsoft Entra ID checks who you are, and your Dataverse security roles and the admin's policies decide what it can do. That makes a few habits essential:

  • Work in a development or sandbox environment first.
  • Use an account with the least privilege that does the job.
  • Approve deletes and other destructive actions yourself.
  • Follow your organisation's data policies and AI policy.

A note on cost

At the time of writing, Dataverse MCP calls from non-Microsoft AI apps use Copilot Credits, with some licences exempt. Check the current Dataverse MCP documentation for your licence before rolling it out.
