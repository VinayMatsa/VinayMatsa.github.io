The story so farThe agent and flows handle customers. Staff need a place to work the same tickets.

From the root: a model-driven app

WhatA model-driven app is built from Dataverse tables, forms, views and dashboards, not drawn screen by screen.
WhyStaff need search, filters, forms and security. Model-driven apps provide them from the data model.

Same moment, different clocks

The chat says first reply by 26 Nov 2026, 11:27 UTC; the app shows 4:57 PM to a user in India. Both are the same stored value. The app converts to each user's time zone; the agent states UTC explicitly. See Part 1.

Watch out

  • Security roles decide who can see and edit tickets; the agent's flows run under their own connection.
  • Views like Open Tickets filter on stored status values.
  • Dashboards use the same views and charts.

Common mistakes

  • A separate staff database the agent can't see.
  • Editable system columns.
  • Staff editing latest update without knowing customers see it.
