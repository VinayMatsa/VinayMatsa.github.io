Azure Blob Storage for files

VM Vinay Matsa 21 November 2026 3 min read

Azure Blob Storage is cheap, large-scale file storage. Flows use it to archive attachments, keep exports too big or too many for SharePoint, and hand files to other systems. Premium, and needs an Azure subscription, so no live demo.

How it's organised

WhatStorage account → containers → blobs (files), with virtual folders in blob names.
WhyLarge volumes of files at low cost, with fine-grained access.
DemoArchive email attachments into year/month folders.

Does someone without an account need it?
Yes
SAS URI with a short expiry
No
Entra ID + a data role on the container

Prefer Entra ID authentication with Storage Blob Data Contributor on just the needed containers; avoid account keys (they open the whole account).
