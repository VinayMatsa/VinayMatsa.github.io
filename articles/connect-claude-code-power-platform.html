Connect Claude Code to Microsoft Power Platform in seven steps

VM Vinay Matsa 11 November 2026 2 min read

I connected Claude Code to Power Platform in my own development environment. Here's the setup, and the things worth knowing before an AI agent touches your environment.

Start from the root

Claude Code is Anthropic's AI coding agent. It runs in your terminal, reads your project and runs commands. Connected to Power Platform, it can build solutions, canvas apps and Power Automate flows using the same command-line tools you would (pac and the Azure CLI) plus Microsoft's MCP servers.

Two questions matter before you start: how does it get access, and what is it allowed to do? The answer to both is "through your sign-in".

The setup in seven steps

  1. Install the prerequisites: Claude Code, the .NET SDK, the Power Platform CLI (pac), Node.js LTS and the Azure CLI. Git is optional, but useful for rolling back.
  2. Verify each install, after reopening the terminal so the new paths load.
  3. Sign in with pac auth create and az login, using the same work account for both.
  4. Start Claude Code in your project folder.
  5. Add Microsoft's power-platform-skills plugins from the official marketplace.
  6. Check the MCP servers with /mcp.
  7. Run a smoke test: "List the solutions in my environment."

What I learned

  • The agent uses your sign-in, so it can do whatever you can do. Nothing more, nothing less.
  • Canvas app work needs an existing saved app, coauthoring turned on and the Studio tab kept open.
  • Keep approvals on and review every change before you publish.
  • Some plugins send usage data to Microsoft by default; you can turn that off.
Guardrails I'd add: a dedicated developer environment, an account without admin rights, Git for every change, and no production access from the agent at all.
