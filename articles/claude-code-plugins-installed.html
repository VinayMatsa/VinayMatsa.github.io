What really gets installed when you add Power Platform plugins to Claude Code

VM Vinay Matsa 12 November 2026 2 min read

I installed three of Microsoft's Power Platform plugins into Claude Code and reloaded once. The counts changed like this:

PartBeforeAfter
Skills019
Agents720
Hooks08
MCP servers04

That's a lot more than "one plugin". Most people install a plugin without knowing what's inside.

Start from the root

Claude Code is an AI coding agent that runs on your computer. A plugin is a package that adds abilities to it. The important thing is that a plugin isn't one thing: it can bring several kinds of component, and they behave very differently.

The parts of a plugin

PartWhat it doesWhen it runs
MarketplaceA repository that lists plugins you can installOnly when you browse or install
PluginThe package that delivers everything belowInstalled once
SkillWritten instructions the agent loads only when a request needs themWhen the AI decides it's relevant
MCP serverTools that actually read or change Power Apps and Power AutomateWhen the AI decides to call a tool
Agent (subagent)A separate helper that takes one focused jobWhen the AI hands work to it
HookFixed code that runs automatically on an eventEvery time the event happens, with no AI decision

The part that surprised me: skills, agents and MCP tools run when the AI decides they're needed, but hooks run every time their event fires. That's why where a plugin comes from really matters.

Before you trust a plugin

  • Install only from the official source (for these, microsoft/power-platform-skills).
  • Install only the plugins you need.
  • Remember that auto-update changes what runs on your PC.
  • Turn telemetry off if you don't want usage data sent.
  • After installing, check /reload-plugins and /mcp to see what was added.
